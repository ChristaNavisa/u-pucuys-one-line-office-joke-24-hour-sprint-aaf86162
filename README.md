[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
bounty on [make.fun](https://make.fun).

## The joke

> The office plant died, so Facilities replaced it with a laminated photo of the plant.

## How it works

`main.ts` (Node 22, stdlib only) writes the joke — one line, 85 characters —
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It validates the line
(1–200 characters, single line, not only whitespace) and is fully
deterministic: every run produces byte-identical output.

```sh
node main.ts
```
